## 🎓 TIPS QUAN TRỌNG

### **Khi đọc tài liệu:**
- [ ] Không chỉ đọc mà phải **hiểu** khái niệm
- [ ] Viết code snippets lại bằng tay
- [ ] Vẽ diagrams trên giấy
- [ ] Nói to giải thích concepts (nghe lại sai chỗ)
- [ ] So sánh với dự án thực: \"Trong dự án tôi...\"

### **Khi practice trả lời:**
- [ ] Dùng concrete examples từ dự án
- [ ] Giải thích **tại sao** chứ không chỉ **cái gì**
- [ ] Nói about trade-offs (ưu & nhược)
- [ ] Admit khi không biết: \"Tôi không chắc, nhưng tôi sẽ...\"
- [ ] Ask clarifying questions

### **Trong phỏng vấn:**
- [ ] Hãy kể về dự án với passion
- [ ] Dùng kinh nghiệm thực tế làm ví dụ
- [ ] Nói về những challenges bạn giải quyết
- [ ] Show curiosity: \"Có thể bạn làm cách nào?\"
- [ ] Ask them meaningful questions

## ❓ SAMPLE QUESTIONS THƯỜNG GẶP

**Easy:**
- Giới thiệu dự án của bạn?
- Tại sao chọn Spring Boot?
- Bạn sử dụng design patterns nào?

**Medium:**
- Mô tả authentication flow?
- N+1 problem là gì? Cách giải quyết?
- JWT vs Sessions - khác biệt?
- Làm thế nào handle optimistic locking?

**Hard:**
- Design system xử lý 1 triệu orders/ngày?
- Làm thế nào scale application?
- Concurrent payment processing - race condition?
- WebSocket vs polling - khi nào dùng cái nào?

**Tricky:**
- Nếu phải rewrite feature này, bạn làm sao?
- Điều gì khó nhất trong project?
- Nếu có time thêm, bạn thêm gì?
- Collaboration với team - conflict case?
